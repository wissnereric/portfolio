Survivor Contest Tracker

Rankings are updated automatically every Thursday at 11 PM UTC via a GitHub Actions workflow. It calls the Claude API (claude-sonnet-4-6) with live web search, which synthesizes the week’s episode recaps and Survivor analysis, then commits updated rankings and commentary directly to this site.
For transparency, the prompt given to Claude is: “It is after Episode N of Survivor 51. Search for recaps and analysis published in the past week. Based on that research, rank all remaining active players from 1 (best positioned to win) to N (worst positioned), considering advantages, jury relationships, alliance standing, and recent challenge and strategic performance. Return rankings plus a 2–3 paragraph plain-text analysis of the episode and current game state.”
Scoring: Win probability (active players, 1/√rank method)
